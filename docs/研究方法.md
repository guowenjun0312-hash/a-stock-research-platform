# 研究方法

## 1. 因子权重学习（代替等权拼分）

样本：主板（60/000/001/002/003，剔除 ST）共 862 只 × 2023-12 至 2026-09。

做法：

- 每个截面交易日（每 5 日取一期），对全体股票计算各因子与未来 5 日收益的
  Spearman 相关系数 IC；
- 汇总 IC 均值、IC 标准差、ICIR = mean(IC)/std(IC)×√期数、方向稳定率；
- 用最近窗口的 ICIR 作为该因子权重（含符号），归一化后写入
  examples/factor_weights.json。

示例结论：

- C 技术层在 5 日口径偏向低吸反转：近 10 日涨停、高 RSI、高换手、高位、高波动
  → 平均跑输（ICIR 为负，应作为减分项）；
- A 基本面（净利/营收增速、ROE、毛利率、现金流）方向稳定为正，用作硬门槛；
- D 情绪层：换手/涨停基因/位置过热减分。

## 2. 等权 vs 学习权重对照

把旧等权分（动量+均线+放量）与学习权重分各取 top/bottom 十分位，对比平均
未来 5 日收益。研究窗口内学习权重的 top 组显著优于等权分 top 组。

## 3. 风格轮动雷达

每日收盘记录：

- 行业涨幅榜/跌幅榜与领涨股；
- 行业/概念主力资金 TOP；
- 涨停结构（连板梯队、炸板率）。

将行业名归类到风格桶：资源周期 / 科技成长 / 消费题材 / 防御红利 / 高端制造 / 其他。
规则：同一风格连续 2 日资金居首才升级为主线；连续切换时提示风格变化；
无主线时标记"混沌"，部门默认降仓等待。

## 4. 决策级回测（不拟合参数，验证自己的判断）

决策账本记录每次最终裁决：日期/代码/方向/参考价/止损/来源/状态。核验口径：

- BUY：按参考价入场，执行止损或持有期末退出，收益 > 0 为胜；
- SELL/回避/空仓：后续走弱为正确；
- HOLD：按持仓纪律核验。

输出：按方向分类的胜率、平均规则收益、盈亏比；用结果反哺纪律
（例如进攻类胜率过低 → 收紧买入标准为稀有动作）。
